> [!NOTE]
> 前置知识

> 一、TEA 魔改是什么意思
>
> TEA是一个教科书级的标准加密算法，结构固定
> ```c
>for (i = 0; i < 轮数; i++) {
>   sum += delta;
>   v0 += (((v1<<6)+k0) ^ (v1+sum+k1) ^ ((v1>>9)+k2) ^ 0x20);
>    v1 += (((v0<<6)+k2) ^ (v0+sum+k3) ^ ((v0>>9)+k3) ^ 0x10);
> }
> ```
>
> 标准TEA中   delta=0x9E3779B9   轮数=32
> 魔改就是把这些标准值故意改掉
>
> 二、z3是什么意思
>
> z3是一个约束求解器
>
> 作用是找到满足全部条件的取值

```python
from z3 import *
s=[Int('s[%d]'%i) for i in range(6)]       #创建一个叫s的python列表，里面装6个z3的符号整数
a=Solver()        #创建一个z3求解器对象，用a指向它
a.add(s[2] - s[3] == 0x84A236FF)
a.add(s[3] + s[4] == 0xFA6CB703)
a.add(s[2] - s[4] == 0x42D731A8)
a.add(s[0] == 0xDF48EF7E)
a.add(s[5] == 0x84F30420)
a.add(s[1] == 0x20CAACF4)
if a.check() == sat:        #check是求解器的检测功能，看看有没有符合条件的解，sat是有解的意思
    print("success")
    answer = a.model()        #返回一个模型对象
    print(answer)
else:
    print("no")
```
